# Order & Profit — запуск на своём компьютере

Этот комплект предназначен для Windows 10/11, 64-bit x64.
Python и зависимости включены. Устанавливать Python, Git, Node или платные
сервисы не нужно. Комплект не использует Cloudflare и GitHub при работе.

1. Распакуйте ВЕСЬ архив в обычную папку на компьютере (например, Документы).
2. Откройте полученную папку Order-Profit-Local и дважды нажмите START.cmd.
3. Задайте пароль кабинета: минимум 16 символов. При вводе символы не видны.
4. Откроется браузер: http://127.0.0.1:8877/. Логин — owner, пароль — заданный.

Пароль действует для текущего запуска и не записывается в файлы. При следующем
запуске можно задать новый. Если браузер помнит старые данные входа, используйте
приватное окно. Для остановки нажмите Ctrl+C в окне программы; дождитесь выхода.
Не нужно держать компьютер включённым постоянно. После остановки или перезагрузки
просто откройте START.cmd снова: карточки и готовые сборки сохраняются.

## Проверить первый цикл

Нажмите «Тестовая карточка», затем «Проверить данные» и «Собрать демо».
После сборки откройте демо, нажмите «Я просмотрел демо», ознакомьтесь со списком
неподтверждённых полей и утвердите версию. В разделе «Письмо» создайте черновик.
Письмо не отправляется. Для проверки реальной клиники создайте новую карточку,
внесите факты и источники в её конфигурацию. Непроверенные сведения не публикуются.

## Что включено

- Карточки клиник, статусы, история, проверка данных и источников.
- Управляющий процесс и очередь, работающие пока открыт кабинет.
- Создание персонального демо из общего ELIT DENT на русском, английском и армянском.
- Проверки сборки, просмотр, правки, утверждение и черновик предложения.
- Сохранение данных между запусками; повторное использование готовых сборок.

## Какие функции исключены из этого варианта

Нет постоянного облачного сервера, доступа с телефона, клиентской ссылки,
фонового исследования клиник, почтовой синхронизации, отправки писем и приёма
оплат. Исследование и ввод данных пока выполняются вручную; готовый черновик
можно скопировать. Не передавайте клиенту адрес кабинета: он доступен только
на вашем компьютере. Закрытый внешний показ демо потребует отдельного решения.

## Данные и расходы

Данные сохраняются вне программы: в папке Order-Profit-Local вашего профиля
Windows (обычно C:\Users\ваше-имя\Order-Profit-Local). Для резервной копии
остановите программу и скопируйте эту папку на свой носитель.

Сам кабинет, стандартная сборка и шаблон письма не вызывают AI/API, не запускают
Codex и не подключают платные услуги. Отдельной оплаты за их запуск нет.
Электричество, интернет и ваша подписка ChatGPT в это утверждение не входят.
Система не работает в фоне после выключения компьютера.

CHECK.cmd запускает автоматические проверки на синтетических данных. Проверки
не отправляют письма и не публикуют сайты; рабочая база пользователя не меняется.

Сохранённые исходники и паспорт версии лежат в app. Проверка паспорта при создании
карточки помогает обнаружить повреждение файлов после распаковки. Полные исходники
остаются в отдельной рабочей ветке существующего DENT-ELIT; production не меняется.
