# Как выложить готовый сайт в интернет — пошагово

Это отдельная инструкция: что делать **после** того, как ИИ уже собрал сайт
по `MASTER_BUILD_PROMPT.md` + `CLIENT_BRIEF.md`, и у тебя на компьютере есть
папка с готовым сайтом (в ней должны быть папки `data`, `content`,
`templates`, `static`, `dist` и файл `build.py`).

Нужны только бесплатные вещи: аккаунт на GitHub, бесплатная программа GitHub
Desktop, аккаунт на Vercel. Платным будет только доменное имя — и то в самом
конце, и только если клиент подтвердил, что сайт нужно вешать на реальный
адрес.

Делай на компьютере (не с телефона) — так проще.

---

## Часть 1. Аккаунт на GitHub (бесплатно)

GitHub — это место, где будет храниться код сайта.

1. Открой сайт **github.com**.
2. Нажми **Sign up** (Зарегистрироваться) в правом верхнем углу.
3. Введи email, придумай пароль, придумай имя пользователя.
4. Подтверди email (придёт письмо со ссылкой — перейди по ней).
5. Готово — у тебя есть аккаунт на GitHub.

## Часть 2. Программа GitHub Desktop (бесплатно, без командной строки)

Это простая программа с кнопками — она загружает файлы с компьютера на
GitHub, набирать никакие команды не нужно.

1. Открой **desktop.github.com**.
2. Нажми **Download for [твоя система]** и установи программу как обычную
   программу (Далее → Далее → Установить).
3. Открой GitHub Desktop, нажми **Sign in to GitHub.com**, войди тем же
   аккаунтом, что создал в Части 1.

## Часть 3. Загрузить папку с сайтом на GitHub

1. В GitHub Desktop выбери **File → Add local repository**.
2. Укажи ту самую папку с сайтом (в ней лежат `build.py`, `data`,
   `templates` и т.д.).
3. Если программа скажет, что это не git-репозиторий и предложит его
   создать — нажми **create a repository**.
4. Впиши название репозитория (например, название клиники латиницей, без
   пробелов: `moya-klinika`), при желании — короткое описание.
5. Оставь галочку **Keep this code private** выключенной, если не против,
   чтобы код был публичным (для бесплатного Vercel это самый простой путь).
   Если код должен быть закрытым — оставь галочку включённой, тоже подойдёт.
6. Нажми **Create repository**, затем **Publish repository** в правом
   верхнем углу окна программы.
7. Готово — весь сайт теперь на GitHub, в твоём аккаунте.

## Часть 4. Один маленький файл для Vercel — `vercel.json`

Vercel должен понять: сайт уже полностью готов (лежит в папке `dist`), его
не нужно ничего "собирать" самому — просто показать как есть.

1. В папке с сайтом (той же, что добавляли в Части 3) создай новый текстовый
   файл с именем ровно `vercel.json` (не `vercel.json.txt` — расширение
   должно быть именно `.json`).
2. Вставь в него ровно это содержимое и сохрани:
   ```json
   {
     "framework": null,
     "outputDirectory": "dist"
   }
   ```
3. Вернись в GitHub Desktop — он покажет, что появился новый файл. Внизу
   слева впиши любое сообщение, например «Добавил vercel.json», и нажми
   **Commit to main**, затем **Push origin** сверху.

## Часть 5. Аккаунт на Vercel и подключение сайта (бесплатно)

Vercel — это то, что показывает сайт в интернете по ссылке.

1. Открой **vercel.com**.
2. Нажми **Sign Up**.
3. Выбери **Continue with GitHub** — так аккаунты сразу свяжутся, и
   пароль придумывать не нужно. Разреши доступ (**Authorize Vercel**).
4. На главной странице Vercel нажми **Add New...** → **Project**.
5. В списке репозиториев найди тот, что создал в Части 3, и нажми **Import**.
6. Vercel сам увидит файл `vercel.json` и настроится правильно. Ничего не
   меняй в настройках — просто нажми **Deploy**.
7. Подожди примерно минуту. Появится надпись **Congratulations!** и ссылка
   вида `https://moya-klinika.vercel.app` — это уже настоящий работающий
   адрес сайта в интернете.

## Часть 6. Проверить сайт

Открой полученную ссылку в браузере (и на телефоне тоже) и убедись, что всё
работает: открывается главная страница, форма записи, переключение языков.

## Часть 7. Доменное имя (платно, только когда клиент подтвердил)

Пока не нужно — сайт уже доступен по бесплатной ссылке `*.vercel.app`. Домен
покупается только когда клиент говорит «беру, вешайте на моё название».

Самый простой способ — купить домен прямо внутри Vercel, тогда всё
настроится само, без лишних шагов:

1. Открой проект в Vercel → вкладка **Settings** → **Domains**.
2. Впиши желаемое название домена (например, `moyaklinika.com`) и нажми
   **Add**.
3. Если Vercel предложит его купить (**Buy**) — оплати картой прямо там,
   цена обычно видна сразу (~10–15 долларов в год для `.com`, зависит от
   зоны). Домен автоматически подключится к сайту — больше ничего делать
   не нужно.

Если домен уже куплен клиентом в другом месте (Namecheap, reg.ru, GoDaddy и
т.п.):

1. Там же в **Settings → Domains** впиши этот домен и нажми **Add**.
2. Vercel покажет две строки — их нужно скопировать и вставить в настройках
   DNS у того сервиса, где куплен домен (раздел обычно называется **DNS
   Management** или **DNS-записи**): одна запись типа **A**, другая типа
   **CNAME** (Vercel сам покажет точные значения — просто скопировать их
   один в один).
3. Подожди — домен подключится обычно в течение часа, иногда до суток.

## Часть 8. Если данные клиента изменились (обновление в будущем)

1. Открой папку с сайтом, попроси ИИ (или сам, если знаешь) поменять нужный
   файл в `data/` или `content/`, затем заново выполнить `python3 build.py`
   и `python3 validate.py` — обязательно дождись `PASSED: 0 errors`.
2. Открой GitHub Desktop — он покажет, какие файлы изменились. Впиши
   сообщение вроде «Обновил цены» → **Commit to main** → **Push origin**.
3. Vercel сам заметит изменения и обновит сайт за ~минуту — заходить в
   Vercel заново не нужно.

## Сколько это стоит

| Что | Стоимость |
|---|---|
| GitHub-аккаунт | Бесплатно |
| GitHub Desktop | Бесплатно |
| Vercel-аккаунт и хостинг (тариф Hobby) | Бесплатно — этого достаточно для такого сайта |
| Доменное имя | Платно, обычно ~10–15$ в год (зависит от зоны), продлевается каждый год |

Всё, кроме домена, — бесплатно и достаточно для полноценно работающего
сайта на своей ссылке.
